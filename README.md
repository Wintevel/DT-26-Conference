# 통합 아이디어톤 주제 뽑기

2026 DT 학술제 통합 아이디어톤(주제: 게임)에서 조별로 **장르 · 특수조건 · 키워드**를 무작위로 뽑는 정적 웹사이트입니다.

## 기능

- 흑백 단일 화면. "뽑기"를 누르면 장르, 특수조건, 키워드 카드 3장이 한 장씩 들어와 뒤집힙니다.
- "다시 뽑기"로 새로 뽑을 수 있고, 바로 직전 결과와 같은 항목은 피합니다.
- 동작 줄이기(reduced motion) 설정에서는 이동·회전 없이 부드럽게 나타납니다.

## 목록 바꾸기

목록은 `data.js`에 있습니다. 한 줄에 한 항목씩 고치면 됩니다.
장르 11개는 확정 목록이고, 특수조건과 키워드는 아직 **예시**입니다.

## 실행

빌드 과정이 없습니다. `index.html`을 브라우저로 열면 바로 동작합니다.

## 배포 (GitHub Pages)

사이트 주소: https://wintevel.github.io/DT-26-Conference/

GitHub Pages는 `gh-pages` 브랜치를 배포합니다. `main`에 푸시하면 `.github/workflows/pages.yml`이 `main` 내용을 `gh-pages`로 복사해서 1~2분 뒤 사이트에 반영됩니다.
